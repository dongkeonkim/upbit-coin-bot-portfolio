# 전략
- 코인별 파라미터 저장 파일: coin_params.json

1. 범용 코인 모델
- 모델: ml_model_GENERIC.json
- 설명: ALLOWED_MARKETS 에 없으면서 TOP N 으로 들어온 코인들에 대해서 적용

2. 단일 코인 모델
- 모델: ml_model_*.json (ml_model_GENERIC.json 제외)
- 설명: ALLOWED_MARKETS 에 있는 코인별로 학습된 모델을 적용
