# EKS Redis 접근 가이드

EKS 클러스터에서 Redis 내부를 확인하기 위한 방법을 설명합니다.

## 1. RedisInsight 웹 UI 접근

### Port Forward 실행

```bash
kubectl -n coinbot port-forward svc/redisinsight 5540:5540
```

백그라운드로 실행하려면:
```bash
kubectl -n coinbot port-forward svc/redisinsight 5540:5540 &
```

### 브라우저 접속

**http://localhost:5540** 접속

> **참고**: Service 이름(`svc/redisinsight`)은 고정이므로 Pod 이름을 확인할 필요 없이 바로 port-forward 가능합니다.

## 2. Redis 데이터베이스 연결 추가

처음 접속 시 Redis 연결을 추가해야 합니다.

1. RedisInsight 웹 UI에서 **"Add Redis Database"** 클릭
2. 연결 정보 입력:
   - **Host**: `redis` (클러스터 내부 서비스명)
   - **Port**: `6379`
   - **Name**: `coinbot-redis` (원하는 이름)
3. **"Add Redis Database"** 버튼 클릭

## 3. redis-cli로 직접 접근 (선택사항)

웹 UI 대신 CLI로 직접 접근하고 싶은 경우:

```bash
# Port Forward
kubectl -n coinbot port-forward svc/redis 6379:6379 &

# redis-cli 접속
redis-cli -h localhost -p 6379
```

### 자주 사용하는 redis-cli 명령어

```bash
# 모든 키 조회
KEYS *

# 특정 패턴 키 조회
KEYS portfolio:*
KEYS candles:*

# 키 값 조회
GET portfolio:default_user
HGETALL candles:KRW-BTC:1m

# 키 타입 확인
TYPE <key>
```

## 4. Port Forward 종료

백그라운드로 실행한 경우:
```bash
# 프로세스 확인
ps aux | grep port-forward

# 종료
kill <PID>
```
