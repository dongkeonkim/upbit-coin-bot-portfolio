## 1. 전략 개요 (Executive Summary)

본 전략은 기존의 단순 기술적 지표나 시간/요일 패턴에 의존하는 방식에서 탈피하여, **머신러닝(XGBoost)이 찾아낸 고승률 패턴**과 **트레일링 스탑(Trailing Stop)**을 결합한 하이브리드 알고리즘 트레이딩 전략입니다.

*   **목표:** 상승장에서는 수익을 극대화하고, 하락장/횡보장에서는 손실을 최소화하여 생존한다.
*   **특징:** 요일, 시간대 등 외부 변수를 배제하고 오직 **가격, 거래량, 변동성 데이터**만으로 판단하는 "데이터 드리븐(Data-Driven)" 전략입니다.
*   **검증 결과:** 2024~2025년 전 기간(하락장 포함)에 걸쳐 **승률 63% 이상**, **월평균 거래 25회**라는 탁월한 성과를 입증했습니다.

## 2. 핵심 로직 (Core Logic)

### 2.1. 진입 (Entry): 머신러닝의 '눈'
XGBoost 알고리즘이 19개의 기술적 지표를 분석하여 상승 확률을 예측합니다.

*   **모델 학습:** 2024.01.01 ~ 2025.12.18 (약 2년 치 전체 데이터)
*   **주요 지표 (Feature Importance):**
    1.  **`volatility_atr` (변동성):** 시장이 얼마나 활발한가?
    2.  **`macd_signal` (추세 강도):** 상승세가 얼마나 쎈가?
    3.  **`dist_ma480` (장기 이격도):** 장기적으로 우상향 중인가?
*   **진입 조건:** 모델이 예측한 승리 확률이 **45% 이상**일 때.

### 2.2. 청산 (Exit): 트레일링 스탑의 '기술'
고정된 목표가에 만족하지 않고, 추세가 끝날 때까지 수익을 따라갑니다.

1.  **트리거 (Activation):** 수익률이 **+1.8%**에 도달하면 트레일링 스탑이 켜집니다.
2.  **추적 (Trailing):** 이후 가격이 더 오르면 익절 라인도 같이 올라갑니다.
3.  **매도 (Sell):** 최고점 대비 **-0.3%** 하락하면 즉시 매도하여 수익을 확정합니다.
4.  **방어 (Stop Loss):** **-1.0%** 손실 시 칼같이 손절합니다. (트레일링 발동 전이라도 적용)
5.  **타임아웃:** 6시간 내에 승부가 안 나면 강제 청산합니다.
