# 퀀트 엔지니어 로드맵 (From Developer to Quant)

이 문서는 소프트웨어 엔지니어가 금융 데이터를 활용해 알고리즘 트레이딩 시스템을 구축하고 발전시켜 나가는 과정을 안내하는 로드맵입니다. 현재 우리가 구현한 `ML Strategy`를 시작점으로 하여, 월스트리트 수준의 시스템으로 나아가기 위한 단계별 가이드를 제공합니다.

---

## 1. 퀀트 투자의 세계관: 엔지니어의 무기

금융 시장은 더 이상 '감'의 영역이 아닙니다. 엔지니어는 다음과 같은 무기로 시장에서 우위를 점합니다.

*   **데이터 (Data):** 시장의 모든 움직임을 기록하고 분석 가능한 형태로 가공합니다.
*   **통계/확률 (Math):** 불확실한 미래를 '확률'로 계산하여 리스크를 관리합니다.
*   **자동화 (Code):** 감정에 휘둘리지 않고 24시간 365일 기계적으로 매매합니다.

---

## 2. 현재 우리의 위치 (Level 1: ML Strategy)

우리는 현재 **지도 학습(Supervised Learning) 기반의 모멘텀 전략**을 구현했습니다.

*   **데이터:** OHLCV (시가, 고가, 저가, 종가, 거래량) 1분봉 데이터
*   **알고리즘:** **XGBoost** (정형 데이터 분류에 강력함)
*   **전략:** 기술적 지표(RSI, MACD, 변동성 등)를 통해 단기 수익 구간 예측
*   **검증:** 슬리피지와 수수료를 고려한 보수적 백테스팅

이 단계에서도 충분히 수익을 낼 수 있지만, 시장 상황이 급변하면 대응력이 떨어질 수 있습니다.

---

## 3. 다음 단계 (Level-Up Roadmap)

혼자서 시스템을 고도화하고 싶다면 다음 순서대로 확장해 보세요.

### Phase 1: 데이터의 확장 (Data Engineering)
더 많은 정보는 더 정확한 예측을 만듭니다.
*   **호가창 데이터 (Order Book):** 단순히 체결된 가격뿐만 아니라, 매수/매도 벽의 두께를 분석합니다. (단기 가격 예측에 필수)
*   **온체인 데이터 (On-chain):** 코인의 실제 이동(고래 지갑, 거래소 유입량)을 추적합니다.
*   **대안 데이터 (Alternative Data):** 뉴스 헤드라인 감성 분석(NLP), 트위터/커뮤니티 여론 분석.

### Phase 2: 모델의 진화 (Alpha Research)
XGBoost를 넘어 시계열 특성을 더 잘 살리는 모델을 도입합니다.
*   **시계열 딥러닝:** **LSTM, GRU, Transformer(Time-Series)**. 과거의 가격 흐름(Sequence) 자체를 패턴으로 인식합니다.
*   **강화 학습 (Reinforcement Learning):** AI 에이전트(Agent)가 가상 환경에서 수억 번 매매하며 스스로 최적의 전략을 깨우칩니다. (AlphaGo 방식)
*   **앙상블 (Ensemble):** 여러 모델(XGBoost + LSTM + 통계적 차익거래)의 의견을 종합하여 최종 결정을 내립니다.

### Phase 3: 시스템 최적화 (System Architecture)
더 빠르고 안정적인 시스템을 만듭니다.
*   **비동기/병렬 처리:** 데이터 수집, 계산, 주문을 동시에 처리하여 지연 시간(Latency)을 줄입니다. (Python `asyncio`, Go, Rust)
*   **이벤트 기반 아키텍처 (Event-Driven):** `Loop` 방식이 아니라, 시장에 새로운 정보가 들어올 때만 반응하는 시스템으로 전환합니다.
*   **리스크 관리 시스템 (RMS):** 주문이 나가기 전에 AI가 아닌 별도의 로직이 "이 주문 위험한데?" 하고 차단하는 안전장치를 만듭니다.

## 4. 필수 학습 키워드

### 프로그래밍 (CS)
*   **Python:** 데이터 분석 생태계 (Pandas, Numpy, Scikit-learn, PyTorch/TensorFlow)
*   **Database:** 시계열 데이터베이스 (TimescaleDB, InfluxDB), 고속 캐시 (Redis)
*   **API & WebSocket:** 실시간 데이터 처리 기술

### 금융 & 수학 (Math/Finance)
*   **시계열 분석 (Time Series Analysis):** 정상성(Stationarity), 공적분(Cointegration)
*   **확률 통계:** 베이지안 통계, 켈리 기준(Kelly Criterion - 자금 관리)
*   **파생상품:** 선물/옵션의 원리, 펀딩비, 레버리지 구조
