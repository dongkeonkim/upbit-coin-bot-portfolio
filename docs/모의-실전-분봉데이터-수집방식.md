# 모의/실전투자시 Upbit API를 통한 분봉 데이터 수집 로직

첫 수집이 8시 25분 인 경우.
1. 8시 26분에 8시 25분봉을 수집 - 거래가 있었음 -> 그대로 저장.
2. 8시 27분에 8시 26분봉을 수집 - 거래가 없었음 (중복된 걸 반환) -> 거래량을 0, candle_time을 26분봉으로 커스텀해서 저장.
3. 8시 28분에 8시 27분봉을 수집 - 거래가 없었음 (중복된 걸 반환) -> 거래량을 0, candle_time을 27분봉으로 커스텀해서 저장.
4. 8시 29분에 8시 28분봉을 수집 - 거래가 있었음 -> 그대로 저장.


업비트 통신시 실패라면 무조건 슬랙 알림
