# 머신러닝(ML) 기반 트레이딩 전략 개발 가이드

이 문서는 `upbit-coin-bot` 프로젝트에서 사용된 머신러닝 전략의 개발 과정, 원리, 그리고 관련 파일들의 역할을 설명합니다.

---

## 1. 핵심 원리: 지도 학습 (Supervised Learning)

우리가 사용한 방식은 ML 중에서도 **지도 학습**입니다. 쉽게 말해, 컴퓨터에게 **"이런 상황에서는 샀어야 했어(정답)"**라는 문제집을 엄청나게 많이 풀게 해서, 실전에서 비슷한 상황이 오면 **"어! 이거 그때 봤던 그 자리인데?"** 하고 맞추게 하는 것입니다.

### 3가지 핵심 요소
1.  **특성 (Features, X):** 판단의 근거가 되는 단서들. (예: 이동평균선 이격도, RSI, 변동성, 거래량 변화 등)
2.  **라벨 (Label, y):** 정답. (예: 지금 사서 6시간 내에 +1.5% 수익이 났으면 `1`, 아니면 `0`)
3.  **모델 (Model):** X와 y 사이의 규칙을 찾아내는 수학적 공식. (우리는 **XGBoost**라는 강력한 알고리즘을 사용함)

---

## 2. 전체 워크플로우 (4단계)

### Step 1: 문제집 만들기 (Data Preparation)
*   **파일:** `backtests/ml_data_prep.py`
*   **하는 일:**
    *   DB에서 코인 가격 데이터(1분봉)를 가져옵니다.
    *   지표(RSI, MACD, 변동성 등)를 계산해 **특성(X)**을 만듭니다.
    *   미래 데이터를 훔쳐보고(?), "여기서 샀으면 익절했을까?"를 계산해 **정답(y)**을 매깁니다.
    *   이때 **슬리피지(체결 오차)**나 **엄격한 익절 기준**을 적용해 문제 난이도를 높여야 실전에서 강해집니다.
*   **결과물:** `backtests/ml_prepared_data.csv` (거대한 엑셀 파일 같은 것)

### Step 2: 공부시키기 (Training)
*   **파일:** `backtests/ml_train.py`
*   **하는 일:**
    *   Step 1에서 만든 문제집을 컴퓨터에게 줍니다.
    *   **XGBoost** 알고리즘이 수백만 개의 데이터를 보며 "어떤 지표가 수익과 가장 관련이 깊은지" 스스로 깨닫습니다.
    *   학습된 지능을 파일로 저장합니다.
*   **결과물:** `backtests/ml_model.json` (이것이 봇의 '두뇌'입니다)

### Step 3: 규칙 확인하기 (Rule Extraction)
*   **파일:** `ml_train.py` 내부 로직
*   **하는 일:**
    *   모델은 수학 공식이라 사람이 이해하기 어렵습니다.
    *   그래서 **의사결정나무(Decision Tree)**를 이용해 모델의 생각을 사람이 읽을 수 있는 **If-Then 규칙**으로 번역해 봅니다.
    *   *예: "변동성이 크고(ATR > 0.005) 60분 이평선 위에 있으면(dist_ma60 > 0) 사라!"*

### Step 4: 모의고사 (Backtesting)
*   **파일:** `backtests/strategy_ml_execution.py`
*   **하는 일:**
    *   만들어진 모델(`ml_model.json`)을 가지고, 과거 데이터 위에서 실제로 매매를 시뮬레이션합니다.
    *   단순 통계가 아니라, **자금 관리, 수수료, 최대 보유 시간** 등 현실적인 제약을 걸고 테스트합니다.
    *   여기서 수익이 나야 실전 투입이 가능합니다.

## 3. 파일별 상세 설명

| 파일명 | 역할 | 실행 명령어 | 중요 포인트 |
| :--- | :--- | :--- | :--- |
| `backtests/ml_data_prep.py` | 데이터 수집 및 가공 | `python backtests/ml_data_prep.py` | `ENTRY_SLIPPAGE`, `STRICT_TP` 등을 조절하여 학습 난이도 조절 가능 |
| `backtests/ml_train.py` | 모델 학습 | `python backtests/ml_train.py` | `PERIODS`를 조절하여 학습 기간 설정 (전 기간 학습 추천) |
| `backtests/strategy_ml_execution.py` | 검증 시뮬레이션 | `python backtests/strategy_ml_execution.py` | **초보수적 설정(슬리피지 0.15% 등)**이 적용되어 있어 실전성 검증에 최적 |
| `services/trading-engine/src/strategy/ml_strategy.py` | 실전 매매 로직 | (봇 실행 시 사용됨) | 실제 봇이 이 파일을 통해 모델을 불러와 매매함 |

## 4. 나만의 전략 만들기 (Customizing)

이 시스템을 이용해 새로운 전략을 만들고 싶다면?

1.  **지표 추가:** `ml_data_prep.py`의 `add_features` 함수에 새로운 지표(예: 볼린저 밴드 폭)를 추가합니다.
2.  **목표 변경:** `ml_data_prep.py` 상단의 `TP`(익절), `SL`(손절) 값을 바꿉니다. (예: 짧게 먹기 -> TP 0.5%)
3.  **재학습:** `ml_data_prep.py` 실행 -> `ml_train.py` 실행.
4.  **검증:** `strategy_ml_execution.py` 실행.

---

## 5. 주의사항 (Tips)

*   **과적합(Overfitting):** 모델이 과거 데이터만 달달 외워서, 미래에는 전혀 안 맞는 현상입니다. 이를 막기 위해 P3(하락장) 같은 어려운 시기를 포함해 학습시키거나, 검증 기간을 따로 두어야 합니다.
*   **현실성:** 백테스트 수익률을 너무 믿지 마세요. 슬리피지와 수수료를 넉넉하게 잡고도 수익이 나야 진짜입니다.
*   **데이터 최신화:** 시장은 변합니다. 한 달에 한 번 정도는 최신 데이터로 모델을 다시 학습(`Retraining`)시켜주는 것이 좋습니다.
