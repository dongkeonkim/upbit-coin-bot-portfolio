# 로컬 K3s 빌드 및 반영

로컬 k3s 클러스터에 서비스를 빌드하고 반영하는 방법입니다.

## 사전 조건

- Docker 실행 중
- k3s 클러스터 실행 중
- 로컬 레지스트리 실행 중 (`localhost:5000`)

## trading-engine 빌드 및 반영

### 1. Docker 이미지 빌드

```bash
cd services/trading-engine
docker build -t trading-engine:latest .
```

### 2. 로컬 레지스트리에 Push

```bash
docker tag trading-engine:latest localhost:5000/trading-engine:latest
docker push localhost:5000/trading-engine:latest
```

### 3. Deployment 재시작

```bash
kubectl rollout restart deployment/trading-engine -n coinbot
kubectl rollout status deployment/trading-engine -n coinbot --timeout=120s
```

### 4. 로그 확인

```bash
kubectl logs deployment/trading-engine -n coinbot --tail=50
```

## 한 줄 명령어

```bash
cd services/trading-engine && \
docker build -t trading-engine:latest . && \
docker tag trading-engine:latest localhost:5000/trading-engine:latest && \
docker push localhost:5000/trading-engine:latest && \
kubectl rollout restart deployment/trading-engine -n coinbot && \
kubectl rollout status deployment/trading-engine -n coinbot --timeout=120s
```

## 다른 서비스 빌드

| 서비스 | 디렉토리 | 이미지명 |
|--------|----------|----------|
| trading-engine | `services/trading-engine` | `localhost:5000/trading-engine:latest` |
| trade-service | `services/trade-service` | `localhost:5000/trade-service:latest` |
| asset-service | `services/asset-service` | `localhost:5000/asset-service:latest` |
| market-data-service | `services/market-data-service` | `localhost:5000/market-data-service:latest` |

## 유용한 명령어

```bash
# Pod 상태 확인
kubectl get pods -n coinbot

# 실시간 로그 확인
kubectl logs -f deployment/trading-engine -n coinbot

# 이전 Pod 로그 확인
kubectl logs deployment/trading-engine -n coinbot --previous

# Pod 재시작 (이미지 변경 없이)
kubectl rollout restart deployment/trading-engine -n coinbot
```
