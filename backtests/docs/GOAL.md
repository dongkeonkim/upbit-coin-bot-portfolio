1. 1분봉마다 변화를 체크하면서 1.5% 이상 올라가는 확률이 -1.0% 이하로 내려가는 확률보다 더 높은 전략을 찾기
2. 수익성 있는 전략 찾기
    - 기대수익률 E[R] > 0
    - 수수료(0.1% 왕복) 포함해서 수익
3. 현실적으로 실행 가능
    - Look-ahead bias 없음 (봉 완성 후 진입)
    - 실제 트레이딩에서 동일한 결과 기대
    - 이미 보유하고 있는 코인 매수 가능. 평균값으로 조정
    - 수수료(0.1% 왕복) 포함해서 수익
4. 충분한 거래 빈도
    - 30일당 15건 이상 (월 15회 이상 거래 기회)
5. 검증된 안정성
    - 여러 기간(P1, P2, P3, P4)에서 일관된 성과 (전부 46% 이상)
    - 여러 코인(BTC, ETH, XRP)에서 작동
(TP +1.8% / SL -1.0%) 고정.


새 신호 발생 시:
  - entry_price = (old * old_qty + new * new_qty) / total_qty
  - TP/SL = 새 평균가 기준으로 재계산
  - hold_period = 새 신호 시점부터 다시 카운트

- 이를 위해서 1분봉을 여러번 쌓아볼 수도 있겠다.

- 한번의 매수 신호에는 전체 자산의 10%씩 투자한다. 즉 10번을 투자하면 투자할 수 없다.
- 6개 코인 동시 보유 가능하지만 각 코인별 전략은 개별 전략으로 달라야 한다.
- 백테스트시에는 슬리피지는 있어야 한다.
- 코인당 최대 3번까지 추가 매수 가능. 예) 첫구매, 두번째 구매, 세번째 구매 (끝)
- 추가진입시 entry_price: 마지막 진입가로 갱신, trailing_active: false로 리셋, entry_time: 현재 시간으로 리셋 (hold_minutes 타이머 재시작)
- 매도는 평균 매수가 기준 -1.0% 이하면 매도


### 백테스트 결과
결과는 기간별, 코인별 수익률, 승률, 매수횟수/매도횟수 가 필요.
