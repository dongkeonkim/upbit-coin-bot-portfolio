## 피처 계산 공식

### 변동성 지표
```python
# ATR (Average True Range)
tr = max(high - low, abs(high - prev_close), abs(low - prev_close))
atr14 = tr.rolling(14).mean()
volatility_atr = atr14 / close

# Bollinger Bands
bb_middle = close.rolling(20).mean()
bb_std = close.rolling(20).std()
bb_upper = bb_middle + 2 * bb_std
bb_lower = bb_middle - 2 * bb_std
bb_width = (bb_upper - bb_lower) / bb_middle

# Squeeze
squeeze = 1 if bb_width < bb_width.rolling(20).mean() * 0.75 else 0
```

### 이동평균 거리
```python
for window in [30, 60, 120, 240, 480]:
    ma = close.rolling(window).mean()
    dist_ma{window} = (close - ma) / ma
```

### RSI
```python
delta = close.diff()
gain = delta.where(delta > 0, 0).rolling(60).mean()
loss = (-delta.where(delta < 0, 0)).rolling(60).mean()
rsi60 = 100 - (100 / (1 + gain / loss))
```

### MACD
```python
ema12 = close.ewm(span=12).mean()
ema26 = close.ewm(span=26).mean()
macd = ema12 - ema26
macd_signal = macd.ewm(span=9).mean()
macd_hist = macd - macd_signal
```

### ADX
```python
plus_dm = high.diff().where(lambda x: x > 0, 0)
minus_dm = (-low.diff()).where(lambda x: x > 0, 0)
plus_di = 100 * plus_dm.rolling(14).mean() / atr14
minus_di = 100 * minus_dm.rolling(14).mean() / atr14
dx = 100 * abs(plus_di - minus_di) / (plus_di + minus_di)
adx14 = dx.rolling(14).mean()
```
