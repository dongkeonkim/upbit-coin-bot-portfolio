각각의 코인이 모든 기간에 수익이 발생해야 해. 손실이 나면 안 돼.

코인은 허용된 6개의 코인만 하면 돼. 비트코인, 이더리움, 리플, 에이다, 솔라나, 
도지.


## 비즈니스 요구사항
실전 vs 백테스트 로직 비교

  | 항목                      | ml_strategy.py (실전)    | run_backtest.py (백테스트)   | 일치 |
  |---------------------------|--------------------------|------------------------------|------|
  | 진입 시점                 | 신호 → 다음 봉 시가      | 동일                         | ✅   |
  | 손절 기준                 | avg_buy_price × 0.99     | 동일                         | ✅   |
  | 손절 체결가               | sl_price (지정가)        | sl_price × 0.9995 (슬리피지) | ⚠️   |
  | 트레일링 트리거           | last_entry_price × 1.018 | 동일                         | ✅   |
  | 트레일링 고점 갱신        | high > peak → 갱신       | 동일                         | ✅   |
  | 트레일링 스탑             | peak × 0.997             | 동일                         | ✅   |
  | 트레일링 체결가           | trailing_stop_price      | trailing_stop_price × 0.9995 | ⚠️   |
  | 시간종료 체결가           | current_price            | close × 0.9995               | ⚠️   |
  | 추가매수 시 트레일링 리셋 | ✅                       | ✅                           | ✅   |
  | 추가매수 시 타이머 리셋   | ✅                       | ✅                           | ✅   |
  | 추가매수 시 peak 갱신     | max(peak, price)         | 동일                         | ✅   |

  핵심 차이점

  슬리피지 적용 방식:
  # run_backtest.py - 모든 청산에 0.05% 슬리피지
  exit_price = sl_price * EXIT_MULT  # EXIT_MULT = 0.9995

  # ml_strategy.py - 지정가 주문 (슬리피지 없음 가정)
  price = sl_price  # 정확한 가격에 청산 시도

  결론:
  - 백테스트가 더 보수적 (슬리피지로 인해 약간 불리한 가격)
  - 실전은 지정가 주문이 정확히 체결되면 약간 더 좋은 결과 기대
  - 로직 자체는 동일 ✅
